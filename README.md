# VR Interview Practice (web demo)

A **scripted** browser demo of the VR Interview Practice project. There is no AI and no server at runtime: the interviewer's
lines are pre-recorded, the answers you type are scored with fixed rules, and the Practice coach page is generated from those
rules. The full version uses a live AI interviewer on Meta Quest.

- Best on desktop Chrome or Edge. Type your answers; the microphone option is off by default and, if you turn it on, your voice
  is sent to the browser vendor's speech service.
- Source: https://github.com/williamthe5thc/vr-interview-simulator
- No real data: all text and voices are fictional/synthetic.
- The interviewer character is from the Microsoft Rocketbox Avatar Library (MIT license).
